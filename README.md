# CodeAlpha Data Science Internship

This repository contains my completed tasks for the CodeAlpha Data Science Internship. Each task is stored in its own folder with the code, dataset, README, and supporting charts.

## Tasks

### [Task 1: Iris Flower Classification](./Task1_CodeAlpha_IrisFlowerClassification)
Classifies iris flowers into three species using K-Nearest Neighbors based on petal and sepal measurements.

**Result:** 100% accuracy on the test set.

### [Task 2: Unemployment Analysis in India](./Task2_CodeAlpha_UnemploymentAnalysis)
Cleans and analyzes unemployment data to measure the impact of the Covid-19 lockdown, including statistical significance testing and a recovery check.

**Result:** Unemployment rose from 9.40% to 20.19% during the Covid peak before falling to 8.03% by November 2020.

### [Task 3: Car Price Prediction](./Task3_CodeAlpha_CarPricePrediction)
Predicts used-car resale prices using features such as present price, age, mileage, fuel type, transmission, and brand. Linear Regression is compared with Random Forest.

**Result:** Random Forest achieved an R² score of 0.958.

### [Task 4: Sales Prediction](./Task4_CodeAlpha_SalesPrediction)
Predicts product sales from advertising spend across TV, Radio, and Newspaper channels and tests the interaction between TV and Radio advertising.

**Result:** Random Forest achieved an R² score of 0.982.
