# CodeAlpha Data Science Internship

This repository contains my completed tasks for the CodeAlpha Data Science Internship. Each task lives in its own folder with its own code, dataset, README, and supporting charts.

## Tasks

### [Task 1: Iris Flower Classification](./Task1_IrisFlowerClassification)
Classifies iris flowers into 3 species using K-Nearest Neighbors, based on petal and sepal measurements.
**Result:** 100% accuracy on the test set.

### [Task 2: Unemployment Analysis (India)](./Task2_UnemploymentAnalysis)
Cleans and analyzes unemployment data to quantify the impact of the Covid-19 lockdown, including a statistical significance test and a recovery check.
**Result:** Unemployment rose from 9.40% to 20.19% during the Covid peak (statistically significant, p < 0.000001), before falling to 8.03% by November 2020.

### [Task 3: Car Price Prediction](./Task3_CarPricePrediction)
Predicts used car resale prices from features like present price, age, mileage, fuel type, and brand, comparing Linear Regression against Random Forest.
**Result:** R² of 0.958 using Random Forest, after discovering and removing motorcycle listings mixed into the raw data.

### [Task 4: Sales Prediction](./Task4_SalesPrediction)
Predicts product sales from advertising spend across TV, Radio, and Newspaper channels, including a test for a synergy effect between channels.
**Result:** R² of 0.982 using Random Forest; confirmed a real TV × Radio interaction effect and found Newspaper spend contributes negligibly.
